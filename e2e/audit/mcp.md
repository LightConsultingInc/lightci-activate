## Server surface

- Every tool's `_meta.ui.resourceUri` = `ui://activate/app.html` (SDK also mirrors `ui/resourceUri`).
- `resources/read ui://activate/app.html` → `text/html;profile=mcp-app`, 723,845 bytes (724,225 after rebuild), 0 external `<script src=http…>`, 0 `<link href=http…>`, 0 `src="http`; `_meta.ui.csp = { connectDomains: [], resourceDomains: [] }`.
- Unauthenticated `POST /mcp` → 401, `WWW-Authenticate: Bearer resource_metadata="http://localhost:4310/.well-known/oauth-protected-resource", scope="openid profile email"`, JSON-RPC error -32001.
- `/.well-known/oauth-protected-resource` → `{ resource: http://localhost:4310/mcp, authorization_servers: [WorkOS issuer], bearer_methods_supported: [header], scopes_supported, resource_name, resource_documentation }`. `/.well-known/oauth-authorization-server` → issuer, authorization/token endpoints, `code_challenge_methods_supported: [S256]`, `grant_types_supported`, jwks_uri, response_types.
